在区域层面，落实“一带一路”、长江经济带建设等国家战略，发挥中心城市作用，推进长江三角洲城市群区域交通一体化，积极落实推动近沪地区（90分钟通勤范围），推动上海与苏州、无锡、南通、宁波、嘉兴、舟山等周边城市协同发展，构建上海大都市圈，打造具有全球影响力的世界级城市群。创新合作模式，构建区域系统发展新机制，实施设施共享、交通互联、文化共融、生态共保、区域共治。

在市域层面，构建“一主、两轴、四翼；多廊、多核、多圈”的空间结构，控制中心城周边区域蔓延，发挥新城、新市镇县人口和带动地区发展的作用。

“一主、两轴、四翼”，即：主城区以中心城为主体，沿黄浦江、延安路- 世纪大道两条发展轴引导核心功能集聚，并强化虹桥、川沙、宝山、闵行4个主城片区的支撑，共同打造全球城市核心区。“多廊、多核、多圈”，即基于区域开放格局，强化沿江、沿湾、沪宁、沪杭、沪湖等重点发展廊道，培育功能集聚的重点发展城镇，构建公共服务设施共享的城镇圈，实现区域协同、空间优化和城乡统筹。为锚固市域空间格局，统筹市域生态、农业和城镇“三大空间”，划定生态保护红线、永久基本农田保护红线、城市开发边界和文化保护控制线，形成“三大空间、四条红线”的空间管控体系，确保城镇空间不被突破，生态、文化空间不被侵占。

与市域空间格局相适应，形成“主城区-新城-新市镇-乡村”组成的市域城乡规划体系。其中，主城区包括中心城和中心城周边的宝山、闵行、虹桥、川沙4个主城片区。新城重点建设以区域重要功能廊道为依托、规划人口规模在50万以上的嘉定、松江、青浦、南桥、南汇5个新城。新市镇突出统筹镇区、街道、集镇和周边乡村地区的作用，分为核心镇、中心镇、中心城周边镇和一般镇协同发展。乡村突出人与自然和谐的宜居功能，重点保护历史文化特色村庄，适度保留资源环境较好、综合评价较高的村庄。

中央活动区包括小陆家嘴、外滩、人民广场、徐家汇等十几个区域，重点发展金融服务、总部经济、商务办公、文化娱乐、创新创意、旅游观光等全球城市核心功能。城市副中心包括五角场等9个主城副中心、5个新城中心和金山滨海地区、崇明城桥地区2个核心镇中心等，发展面向长三角和市域的综合服务中心，兼顾全球城市部分核心功能。地区中心和社区中心主要承担所在区域的公共服务。

### 2026-09 更新 <a name="发展规划2026"></a>

**（1）"十四五"（2021—2025）收官要点**

* 2025年全市生产总值（GDP）56708.71亿元（约5.67万亿元），比上年增长5.4%，经济总量继续保持全国城市首位，是全国首个GDP突破5万亿元的城市。来源：上海市统计局2025年统计公报，2026-03-30，https://tjj.sh.gov.cn/tjgb/20260330/e0772941e8e041eaaad2df850b44ef98.html
* 2025年第三产业增加值占GDP比重79.3%；战略性新兴产业增加值占GDP比重25.3%；全社会研发经费支出相当于GDP比例约4.5%。上海港集装箱吞吐量5506.25万国际标准箱（+6.9%）。来源：同上统计公报。

**（2）"十五五"规划纲要要点（与城市发展/房地产相关）**

### 落户2026 <a name="落户2026"></a>

**（1）居转户（新版办法沪府规〔2025〕8号，2025-12-01施行，有效期至2030-11-30）**

* 基本条件（须同时满足）：持《上海市居住证》累计满7年；持证期间按规定参加本市职工社保累计满7年；依法在本市缴纳个税；在本市被评聘为中级及以上专业技术职务或具有技师（国家二级）以上职业资格。
* 激励条件：最近4年内累计36个月及申报当月社保基数达上年度本市社平工资2倍的，可不受职称/职业资格限制（7年路径免职称）；达社平工资3倍的，持证及参保年限可缩短至5年。来源：上海市政府《〈持有上海市居住证人员申办本市常住户口办法〉解读》，2025-11-30，https://www.shanghai.gov.cn/wzjd/20251130/c743561cb6d64814a01e8f60f6da118b.html
* 重点区域（临港新片区、张江科学城、五个新城、南北转型地区、崇明生态岛）另有缩短年限等特殊支持政策。

**（2）应届生落户（2026年通知）**

* 直接落户：博士研究生；在沪各高校/科研院所应届硕士、全国"双一流"建设高校应届硕士；**本科阶段为清华大学、北京大学及在沪"世界一流大学建设高校"（复旦、交大、同济、华师大）的应届本科生**，符合基本条件即可直接落户；在沪"双一流"建设高校应届本科到五大新城/南北转型重点区域就业的可直接落户。
* 不符合直接落户者按要素打分，**2026年进沪落户标准分为72分**。来源：上海市教委通知，2026-05-06，https://edu.sh.gov.cn/xxgk2_zdgz_xxxsgz_01/20260506/f4df3bb5b82747b893b1eb10ca2b1f8b.html ；评分办法转载，http://sh.bendibao.com/zffw/2026513/305923_2.shtm

**（3）留学生落户（新版实施细则，2025-12-01发布）**

* 留学人员应在回国后2年内来上海并持续在沪工作；按学历档次对应社保要求（前4类人员最近连续6个月社保基数不低于上年度社平工资；第5类人员最近连续12个月不低于社平工资1.5倍）；社保与个税须合理对应、不得补缴。来源：一网通办"留学回国人员户口申办"，2026-09更新，https://zwdt.sh.gov.cn/qykj/shell_oc_policy_zq/policy/project-detail?freeEnjoy=false&id=67ac455370f4a76abc6e0aad
* 【待核实】境外院校世界排名分档（前50/100等）具体名单，以上海市人才网 sh-italent.com 最新办事指南为准。

**（4）居住证积分**

* 标准分值120分，达标可享受子女教育等公共服务待遇。社保基数积分：最近4年内累计36个月社保基数达社平2—3倍积100分、达3倍（最近3年累计24个月）积120分；社保每满1年积3分；本科+学士90分、硕士100分、博士110分。来源：一网通办积分核定页，https://zwdt.sh.gov.cn/govPortals/bsfw/item/40bad145-c9af-4f25-a616-d96be86db5d4 ；积分打分计算器 https://jzzjf.rsj.sh.gov.cn/jzzjf/pingfen/zc2.jsp
* 【待核实】2025—2026年积分120分体系是否有新增加分指标微调，以 rsj.sh.gov.cn 积分专栏最新公告为准。

### 限购2026 <a name="限购2026"></a>

**当前（截至2026-09）限购口径，Q&A式梳理：**

**Q1：沪籍居民家庭/成年单身（单身按家庭执行）能买几套？**
A：在外环外购买住房（新建商品+二手）不限套数；在外环内限购2套。来源：上海市房屋管理局《关于优化调整本市房地产政策措施的通知》，2025-08-25（08-26施行），https://fgj.sh.gov.cn/qtgw/20250825/ac8bba5cc87a40ce862ffd011093866f.html

**Q2：非沪籍居民家庭/成年单身（2026-02-26起最新）能怎么买？**
A：
* 在外环外购房：社保或个税连续缴纳满1年及以上即可，不限套数（延续2025-08-26政策）；
* 在外环内购房：社保或个税连续缴纳满1年及以上，限购1套（2026-02-25由原"满3年"降为"满1年"）；
* 社保或个税连续缴纳满3年及以上：在执行现有限购基础上，可在外环内增购1套（即外环内最多可购2套）；
* 持《上海市居住证》满5年及以上：在本市限购1套住房。
来源：《关于进一步优化调整本市房地产政策的通知》（沪建房管联〔2026〕75号），2026-02-25（02-26施行），https://fgj.sh.gov.cn/qtgw/20260225/6c4c4d2c6f1a41638d98e107c1eb6ca7.html ；上海市政府转发，2026-02-27，https://www.shanghai.gov.cn/nw31406/20260227/961ca351f504470f90ff4d3d001bb613.html

### 税费2026 <a name="税费2026"></a>

**（1）契税（2024-12-01起执行，2025—2026延续）**

依据财政部 税务总局 住房城乡建设部公告2024年第16号（上海自2024-12-01起与全国统一适用，含二套优惠）：
* 家庭唯一住房：面积≤140㎡减按1%；面积>140㎡减按1.5%。
* 家庭第二套住房：面积≤140㎡减按1%；面积>140㎡减按2%。
* 第三套及以上：按3%法定税率征收。
* 注：优惠面积标准由原90㎡提高到140㎡；北上广深二套契税优惠同步与全国统一。
* 来源：国家税务总局政策法规库，2024-11-12，https://fgk.chinatax.gov.cn/zcfgk/c102416/c5235817/content.html ；上海2026税费梳理，https://www.shanghai.gov.cn/nw17239/20260423/db84274a588149309032977a3df7f916.html

**（2）增值税及附加**

* 满2年（含2年）对外销售：免征增值税；不满2年：按3%征收率全额缴纳（自2026-01-01《增值税法》施行后，征收率由原5%调整为3%；应纳税额=含税销售额÷(1+3%)×3%）。持有年限以产权证或契税完税证明时间"孰先"为准。
* **上海自2024-11起已取消普通住房和非普通住房标准**，与全国统一适用上述增值税政策（不再有非普通住宅差额征收一说）；增值税征免年限由5年改2年始于2024-09-29。
* 来源：财政部/税务总局公告2025年第17号，https://www.gov.cn/zhengce/zhengceku/202512/content_7053266.htm ；上海市房屋管理局，2024-11-19，https://fgj.sh.gov.cn/gzdt/20241119/fb34dd47475645b192163e683af0f430.html

**（3）个人所得税**

* "满五唯一"（个人转让自用5年以上、且是家庭唯一生活用房）：免征个人所得税。
* 不满足"满五唯一"：按财产转让所得差额20%据实征收；不能提供完整原值凭证的，按住房转让收入核定征收1%。
* 换房"卖一买一"个税退税：自2026-01-01至2027-12-31，出售自有住房后1年内在同一城市重新购房的，对出售现住房已缴个税予以退税（新购金额≥现住房转让金额的全额退还，新购金额<的按比例退还）。
* 来源：国家税务总局上海市税务局，2026-01-15，https://shanghai.chinatax.gov.cn/zcfw/zcfgk/grsds/202601/t479055.html

**（4）个人住房房产税（上海试点，持续优化中）**

* 征收对象：本市居民家庭新购且属于该家庭第二套及以上的住房，以及非本市居民家庭在本市新购的住房。
* 税率：暂定为0.6%；应税住房每平方米交易价格低于上年度本市新建商品住房平均销售价格2倍（含）的，税率暂减为0.4%。**2026年税率分界线为92536元/㎡**（以2025年新建住宅均价46268元/㎡×2计算，2018年以来首次下调）。
* 免税面积：沪籍家庭合并计算全部住房面积，人均60㎡（含）以内免征。
* 2026-01-01起新增：本市户籍居民家庭中的子女成年后，购买住房属于成年子女家庭唯一住房的，暂免征收个人住房房产税。
* 来源：新民晚报，2026-03-10，https://paper.xinmin.cn/html/xmwb/2026-03-10/8/233246.html ；沪建房管联〔2026〕75号，https://fgj.sh.gov.cn/qtgw/20260225/6c4c4d2c6f1a41638d98e107c1eb6ca7.html
* 注：印花税对个人销售/购买住房全额免征。

## 3.5 <a name="其他费用">其他费用</a>
因为目前很多上家是到手价，所以一定需要和中介经纪确认清楚涉及的所有费用，避免出现签约后面又出来各种奇奇怪怪的费用，我在购房中了解到的几个其他费用：
1. 卖家的一些材料公证的费用
2. 交房时结算水电，煤气，网络，有线电视，物业费等，所以最好尾款压5-10万，交房当天结算
3. 上家房子中装修和家具的部分，签订合同时约定是否搬走还是留给下家，费用如何计算
