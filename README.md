# Part 1: <a name="宏观政策">宏观政策与分析</a>
## 1.1 <a name="城市定位">城市定位</a>
《上海市城市总体规划（2017—2035年）》（简称"上海2035"）是上海城市规划、建设和管理的法定依据。官方原文可查阅：

* [上海市城市总体规划（2017-2035年）全文 PDF —— 上海市人民政府](http://www.shanghai.gov.cn/newshanghai/xxgkfj/2035002.pdf)
* [上海市城市总体规划专题页 —— 上海市人民政府](https://www.shanghai.gov.cn/nw42806/)
* [总体规划（含国务院批复国函〔2017〕147号）—— 上海市规划和自然资源局](https://ghzyj.sh.gov.cn/gtztgh/20230920/9799aa7eeed84b8aa318983474f9eccf.html)

**城市性质：** 上海是我国直辖市之一，长江三角洲世界级城市群的核心城市，国际经济、金融、贸易、航运、科技创新中心和文化大都市，国家历史文化名城，并将建设成为卓越的全球城市、具有世界影响力的社会主义现代化国际大都市。

**城市目标愿景：** 卓越的全球城市，令人向往的创新之城、人文之城、生态之城，具有世界影响力的社会主义现代化国际大都市。

**五年实施评估（2025年10月）：** 2025年10月17日，上海市规划委员会全体会议审议"上海2035"总规五年实施评估报告和动态维护规划方案。当前官方正式对外的总目标表述统一为"具有世界影响力的社会主义现代化国际大都市"。来源：[上海市人民政府，2025-10-18](https://www.shanghai.gov.cn/nw4411/20251018/ae04e16c98b940df90a4f7a3e7949f94.html)；[市规划资源局，2026-08-11](https://ghzyj.sh.gov.cn/hyxw/20260812/71f03b57aeec4e848798b930f9a83711.html)。【待核实】"卓越的全球城市"原表述在动态维护文本中是否保留或被替换，检索方向：市规划资源局"规划公示"栏。

**《上海市"十五五"规划纲要》（2026年2月发布）：** 城市定位表述为"加快建成国际经济、金融、贸易、航运、科技创新中心和具有世界影响力的社会主义现代化国际大都市"；2035年远景为"五个中心"功能全面升级、人均地区生产总值比2020年翻一番、基本建成具有世界影响力的社会主义现代化国际大都市。来源：[《上海市国民经济和社会发展第十五个五年规划纲要》，2026-02-10](https://www.shanghai.gov.cn/nw12344/20260210/86c10a3ea525407e84d4d7354c8fcb4e.html)。

## 1.2 <a name="人口目标">人口目标</a>
"上海2035"严格控制常住人口规模，至2035年常住人口控制在2500万人左右，并守住人口规模、建设用地、生态环境、城市安全四条底线。

* **截至2025年末，全市常住人口为2485.41万人**，其中户籍常住人口1510.91万人、外来常住人口974.50万人；全年出生10.7万人、死亡16.4万人，自然增长率-2.3‰。距2035年2500万左右目标余量约14.6万人，人口已进入低速微增/总量趋稳阶段。来源：[上海市统计局《2025年上海市国民经济和社会发展统计公报》，2026-03-30](https://tjj.sh.gov.cn/tjgb/20260330/e0772941e8e041eaaad2df850b44ef98.html)。
* "十五五"规划把建设用地总规模不突破3200平方公里作为约束性要求。来源：[《上海市加强土地管理"十五五"规划》，2026-07-31](https://www.shanghai.gov.cn/gwk/search/content/9799730c0232457391b56ffe5c6e00a7)。
* 【待核实】2025—2026年是否有官方上调或松动2500万人口红线的表述——目前检索未见，动态维护规划方案全文未公开。

## 1.3 <a name="发展规划">发展规划</a>
在市域层面，"上海2035"构建"一主、两轴、四翼；多廊、多核、多圈"的空间结构：主城区以中心城为主体，沿黄浦江、延安路—世纪大道两条发展轴引导核心功能集聚，强化虹桥、川沙、宝山、闵行4个主城片区；基于区域开放格局，强化沿江、沿湾、沪宁、沪杭、沪湖等重点发展廊道。市域形成"主城区—新城—新市镇—乡村"的城乡规划体系，重点建设嘉定、松江、青浦、南桥、南汇5个新城。公共活动中心体系由中央活动区（城市中心）、城市副中心、地区中心、社区中心四个层次组成。

**2025年土地市场：** 公开招拍挂口径全年成交48宗涉宅用地，土地出让金1427.23亿元（同比+1.9%）；全口径（含协议/遴选/股权交易）约2453亿元，已形成"公开出让+协议/遴选"双轨模式。2025年被称"地王年"：徐汇东安地块439.53亿元为全国总价地王，徐汇衡复地块楼面价20.03万元/㎡为全国单价地王，全年4幅地块溢价率超40%。来源：[证券时报引中指研究院，2026-01-05](https://www.stcn.com/article/detail/3569447.html)；[界面/新浪财经，2026-01-07](https://finance.sina.com.cn/jjxw/2026-01-07/doc-inhfmtvx4910650.shtml)。

## 2.1 <a name="了解自己的需求">了解自己的需求</a>
了解自己的需求，比了解宏观形势和市场行情有时更重要。近年（2025—2026）上海楼市明显分化：核心滨江/高端盘（如徐汇滨江、前滩、大宁）靠产品力持续热销甚至触发积分，而多数普通盘取消摇号、以价换量；选房时应先想清楚自己的核心诉求。
1. 刚需or改善
2. 居住需求or投资保值需求：居住需求侧重地段、小区、户型等整体居住条件；投资需求可参考近年板块年化回报（过去十余年核心板块约年化数个百分点，但波动加大、需自担风险）。
3. 学区房
4. 新房or二手房
5. 老房子or次新房

## 3.4 <a name="交易流程与税费">交易流程与税费</a>
关于税费和流程，最好请经纪帮你算清楚、解释清楚；如果找的不是大型中介，一定要提前了解清楚涉及的所有税费和其他费用，避免签约后又冒出各种费用套路。

**（1）契税（2024-12-01起，2026年延续）：** 家庭唯一住房，≤140㎡按1%、>140㎡按1.5%；家庭第二套，≤140㎡按1%、>140㎡按2%；第三套及以上按3%。优惠面积标准已由90㎡提高到140㎡。来源：[国家税务总局政策法规库](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5235817/content.html)。

**（2）增值税及附加：** 满2年（含）对外销售免征；不满2年自2026-01-01起按3%征收率全额缴纳（原5%）。上海自2024-11起已取消普通/非普通住宅标准。来源：[财政部/税务总局2025年第17号公告](https://www.gov.cn/zhengce/zhengceku/202512/content_7053266.htm)。

**（3）个人所得税：** "满五唯一"（自用5年以上且家庭唯一生活用房）免征；否则差额20%或核定1%。"卖一买一"换房个税退税延续至2027-12-31。来源：[上海市税务局，2026-01-15](https://shanghai.chinatax.gov.cn/zcfw/zcfgk/grsds/202601/t479055.html)。

**（4）个人住房房产税（上海试点）：** 征收对象为本市居民家庭新购第二套及以上住房、非本市居民家庭新购住房；税率0.6%（低于上年度新建商品住房均价2倍的减按0.4%），**2026年分界线为92536元/㎡**；沪籍家庭人均60㎡以内免征；2026-01-01起成年子女购房为其家庭唯一住房的暂免。来源：[新民晚报，2026-03-10](https://paper.xinmin.cn/html/xmwb/2026-03-10/8/233246.html)。

## 3.5 <a name="其他费用">其他费用</a>
